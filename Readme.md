# Cinema Ticket Booking System

A simple console-based Cinema Ticket Booking System built in C as my first-semester Programming Fundamentals project.

## Features
- View available seats
- Book tickets
- Cancel tickets
- Calculate ticket costs
- Validate booking and cancellation quantities

## Technologies
- C
- Standard I/O
- Basic control structures and functions

## How to Run
1. Compile the source file using a C compiler.
2. Run the generated program.
3. Select an option from the main menu.

Example:
`gcc cinema.c -o cinema`

On Windows:
`cinema.exe`

## What I Learned
- Conditional statements and switch cases
- Loops and user input
- Basic booking logic
- Tracking available seats

## Project Status
Basic academic project. Future improvements could include individual seat selection and persistent booking records.
